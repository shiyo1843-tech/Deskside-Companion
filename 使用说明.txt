桌边伙伴 · Windows 快速使用

双击「桌边伙伴.exe」。移动程序时请复制整个 Windows 文件夹。
角色太亮或太暗，可打开「显示 → 当前角色的灯光亮度」。100% 使用该类材质的默认打光，选择的亮度会随这个角色保存。
鼠标中键按住角色左右拖，可连续旋转一整圈。角色获得焦点后，按 ← / → 每次转 1°。显示页也能微调角度。
人形角色默认会散步、收步和休息。右键轮盘 → 动作 → 待机姿势，可选自动、站着、面向你蹲下或趴着看四周。
走到目的地后，角色先收步，再原地换脚转向屏幕。转身期间也能用中键拖动或方向键接管朝向。
没有人形骨架的模型也能自动移动、回正和轻跳。带有可识别的行走片段时优先播放模型自己的片段，其余模型用小跳步。动作菜单可切换「自动活动」和「原地待机」。表情、单件衣物和可抓发束取决于文件里的数据。
自主动作默认间隔 45–80 秒，可在「显示」中调节。关闭走动后仍可原地换姿势。
轮盘 → 表情 → 跟随动作，可让角色在做动作时带上自己的表情；选具体表情可以固定。控制台左侧预览也可按住左键左右拖动，连续转身。
聊天回复会显示在角色头像对白框中，长消息自动翻页，聊天页保留全文。「显示」中可以分别关闭自由走动和桌面气泡。
鼠标扫过发丝会把它拨开。左键轻点眼睛会闭眼。按住可抓取的发束、耳朵或衣摆约四分之一秒，再移动鼠标，松开会回弹。
在角色身上按住右键约四分之一秒，再移动鼠标，就会把她拎起来。拖动时她跟着鼠标走，双脚悬空。松开后落下，恢复原来的姿势。静态模型也可以拎起。轻点右键或按 Ctrl + Alt + P 打开紫色轮盘。
轮盘顶端的「角色菜单」是这个模型自己的菜单。点圆心返回，也能从「表情」「衣装」「动作」选常用项目。
进入「角色 → 导入模型」可添加 .vrm、.glb、.petmodel 或 .unitypackage。在角色列表点选即可切换。角色和对话在下次打开时会找回。
导入 Unity 资源包时优先选角色根 Prefab。首次转换需要本机 Unity；若角色用到了 VRChat SDK 或第三方着色器，可在同一窗口选择已装好依赖的本机工程。导入成功后直接从列表使用。包内已有 VRM、GLB 或 .petmodel 时可直接读取。
右键轻点 → 角色菜单。带原版 VRChat 菜单的角色会显示它的图标和子菜单。其他模型根据文件生成可用项目，Eku 可在「模型表情」里选「开心」，在「衣装与配件」里开关 Jacket。
VRChat 工程只需在原 Unity 工程里用随附的「桌宠角色导出工具」导出一次。之后换角色直接在桌宠中完成。
轮盘「聊天」可以打中文。

想看聊天动作，可以说“朝我挥挥手”或“笑一下”。在「显示」页可单独开关「让 AI 随聊天做动作和表情」。
点「接入自己的 AI」，填写你选的 Chat Completions 兼容服务的接口地址、模型名和 API Key，再点「保存并开始聊天」。以 /v1 结尾的基础地址会自动补全，本机免密服务可留空 Key。密钥由 Windows 在本机加密，也可以从环境变量读取。
对话按角色、接口和模型分别保存。已经配对璃伴的用户还可选择自己的云端人格。使用普通 API 无需璃伴。
「显示」里有四档渲染像素。鼠标滚轮改变桌面角色大小。「收起」只关闭面板，轮盘「桌宠设置 → 退出桌宠」会退出程序。
更多格式说明、第三方模型的适配范围与重新构建方法见《使用说明.md》。
